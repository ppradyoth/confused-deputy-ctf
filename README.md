# Confused Deputy CTF

An AI security playground built around a single vulnerability class — the confused deputy problem — expressed through four agentic attack surfaces: tool privilege escalation, poisoned retrieval, judge deception, and orchestrator manipulation.

Sibling project: [prompt-injection-ctf](https://github.com/ppradyoth/prompt-injection-ctf) covers single-turn prompt injection and jailbreaking. This one covers agentic failure modes.

See [DESIGN.md](DESIGN.md) for the full design doc — level specs, architecture, framework mapping (OWASP LLM Top 10 / MITRE ATLAS), and the phased development plan.

Status: design phase, not yet implemented.
